# Carokaz Mada — flux produits Google

Le fichier `carokaz-merchant-mg.xml` est un flux RSS/Google Merchant Center généré à partir des 17 véhicules actifs relevés dans la boutique Carokaz Mada. Les URLs produit et les images pointent vers `https://carokazmada.com`.

URL publique : `https://carokazmada.github.io/feeds/carokaz-merchant-mg.xml`

Le flux est un instantané. Il doit être régénéré après une modification importante de l’inventaire jusqu’à ce qu’un accès Merchant Center ou une tâche de publication inter-dépôts soit autorisé.
